### Selected work

- **[SSDLabeler](https://github.com/AkimaCon/SSDLabeler)** — semi-synthetic data generation for multi-label artifact classification in EEG, validated across 52 subjects. Published in *Scientific Reports* (2026), co-first author.
- **[NeuroFusion-RAG](https://github.com/AkimaCon/NeuroFusion-RAG)** — a local retrieval-augmented QA system over EEG/neuroscience literature, built to get hands-on with LLM application patterns. Hybrid retrieval (BM25 + dense) with LangGraph, ChromaDB, and Llama 3 via Ollama; FastAPI backend, Streamlit UI, and Docker-based local deployment.
